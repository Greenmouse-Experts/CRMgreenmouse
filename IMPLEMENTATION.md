# Greenmouse CRM Implementation Tracker

Comprehensive tracking document for API integration, TanStack Router routes, and UI components based on [`docs/api/`](./docs/api/) and [`Greenmouse CRM API.postman_collection.json`](./Greenmouse%20CRM%20API.postman_collection.json).

## 📌 Architecture & Design Standards

| Layer                   | Standard                                                                                                    | Details                                                                                                                                                                                                          |
| :---------------------- | :---------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **API Client**          | [`src/api/simpleApi.ts`](./src/api/simpleApi.ts)                                                            | Base URL: `https://crmgrenmouse-backend-api.onrender.com/`. Interceptor automatically injects `Authorization: Bearer <accessToken>`. Handles 401 unauthenticated states.                                         |
| **Data Fetching**       | TanStack Query v5                                                                                           | All queries and mutations centralized under [`src/api/`](./src/api/) (`adminApi.ts`, `tenantApi.ts`, `crmApi.ts`, `catalogApi.ts`, `financeApi.ts`, `salesApi.ts`, `supportApi.ts`). Target: **Zero mock data**. |
| **Toolchain & Runtime** | `bun` (v1.4+)                                                                                               | All commands, package management, builds, and typechecks execute via `bun` (`bun run typecheck`, `bun run build`, `bun run dev`).                                                                                |
| **Typecheck**           | `bun run typecheck`                                                                                         | Invokes `tsgo --noemit`. Zero TypeScript compilation errors enforced across codebase.                                                                                                                            |
| **Page Loading**        | [`PageLoader.tsx`](./src/components/layout/PageLoader.tsx)                                                  | Full page/section animated loading state with error boundary, refetch CTA, and empty states.                                                                                                                     |
| **Component Loading**   | [`QueryCompLayout.tsx`](./src/components/layout/QueryCompLayout.tsx)                                        | Widget-level loader for embedded charts and stats cards.                                                                                                                                                         |
| **Table Actions**       | [`pop-up.tsx`](./src/components/tables/pop-up.tsx)                                                          | Passed via `actions: Actions<T>[]` prop to `CustomTable`. Renders portal-positioned dropdown menu.                                                                                                               |
| **Table Search**        | [`ContainerRow.tsx`](./src/components/ContainerRow.tsx) & [`Searchbar.tsx`](./src/components/Searchbar.tsx) | DaisyUI modernized search bar integrated seamlessly into container toolbars.                                                                                                                                     |
| **Modals**              | [`DialogModal.tsx`](./src/components/DialogModal.tsx)                                                       | Accessible `<dialog>` with backdrop, imperative `open()` / `close()`, header close button, and unmount on close.                                                                                                 |
| **Styling**             | Tailwind CSS 4 + DaisyUI 5                                                                                  | Primary color `#007047`. Glassmorphism and responsive drawer navigation.                                                                                                                                         |

1. **Phase 1: Tenant Core Operations (Zero Mock Data)**
   - Wire [`/tenant/contacts/customers`](./src/routes/tenant/contacts/customers/index.tsx) and [`/tenant/contacts/companies`](./src/routes/tenant/contacts/companies/index.tsx) to `useContacts` and `useCompanies`.
   - Wire [`/tenant/products`](./src/routes/tenant/products/index.tsx), [`/tenant/products/service`](./src/routes/tenant/products/service/index.tsx), and [`/tenant/products/categories`](./src/routes/tenant/products/categories/index.tsx) to `useProducts`, `useServices`, and `useCategories`.
   - Wire [`/tenant/orders`](./src/routes/tenant/orders/index.tsx) to `useOrders`.

2. **Phase 2: Tenant Billing & Financial Records**
   - Wire [`/tenant/accounts/Invoices`](./src/routes/tenant/accounts/Invoices/index.tsx) and detail/add routes to `useInvoices` and `useCreateInvoice`.
   - Wire [`/tenant/accounts/income-expenses`](./src/routes/tenant/accounts/income-expenses/index.tsx) and [`/tenant/accounts/transactions`](./src/routes/tenant/accounts/transactions/index.tsx) to live income & expense queries.
   - Wire [`/tenant/subscription`](./src/routes/tenant/subscription/index.tsx) to live tenant subscription hooks (`useTenantCurrentSubscription`, `useTenantSubscriptionPlans`, `useUpgradeSubscription`).

3. **Phase 3: Workspace Users & Settings**
   - Wire [`/tenant/users`](./src/routes/tenant/users/index.tsx) and [`/tenant/users/roles`](./src/routes/tenant/users/roles/index.tsx) to `useStaffs` and `useRoles`.
   - Wire [`/tenant/settings/profile`](./src/routes/tenant/settings/profile/index.tsx) and [`/tenant/settings/security`](./src/routes/tenant/settings/security/index.tsx) to `useTenantMe` and password update mutations.

4. **Phase 4: Sales Pipeline & New Modules**
   - Build Deals visual Kanban board (`/tenant/deals`) using `/v1/deals` and `/v1/pipelines`.
   - Build Leads qualification board (`/tenant/leads`) using `/v1/leads`.
   - Build Support Ticket helpdesk thread UI (`/admin/support` and `/tenant/support`) using `supportApi.ts`.
